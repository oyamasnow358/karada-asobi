# からだで あそぼ（MieeL）

iPad のカメラで からだの うごきを よみとって あそぶ、感覚統合・運動あそび用の アプリです。
映像は保存・送信せず、iPad の中で からだの点（MediaPipe Pose）だけを使います。

| あそび | からだの つかいかた |
|---|---|
| 🎈 ふうせん わり | 手を のばす・正中線を こえる・目と手の協応 |
| 🐦 とりに なって とぼう | 両手を いっしょに パタパタ（両側協調・リズム） |
| 🐸 ぴょんぴょん ジャンプ | タイミングを あわせて ジャンプ（すわって モードは バンザイ） |
| 🙈 だるまさんが ころんだ | うごく ↔ ピタッと とまる（抑制の コントロール） |
| 🤸 まねっこ ポーズ | おてほんと 同じ ポーズ（ボディイメージ・左右） |

- 子どもは 5つの キャラクター（くま・うさぎ・ねこ・ロボ・かえる）に へんしん。カメラ映像を 出さない「キャラ」表示が 基本。
- ⚙️ ながおし：すわって モード・じかん・むずかしさ・みため・音・きろく（CSV）

## つくりかた
```
python _src/build.py        # _src/ → index.html, sw.js
python -m http.server 8821  # http://localhost:8821/
```
